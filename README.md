# 🛒 Flipkart Inspired E-Commerce UI

This is a simple e-commerce website that I created using HTML and CSS.

I created this project to practice frontend development and to understand how an online shopping website is structured.

## 🖥️ About the Project

The website has a simple e-commerce layout with products, categories and offers.

### Features

- Navigation bar
- Search bar
- Product categories
- Hero banner
- Product cards
- Offers section
- Add to Cart buttons
- Responsive design
- Footer section

## 🛠️ Technologies Used

- HTML
- CSS
